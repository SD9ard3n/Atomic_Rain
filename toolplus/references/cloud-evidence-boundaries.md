# 云安全证据边界

用途: 只承接云线索、云凭据和对象存储类问题的横向证据、评级、HITL 和误判过滤。具体厂商命令和元数据路径仍回到 [cloud-security.md](cloud-security.md) 或 `references/technologies/`。

---

## 使用时机

- 发现 AK/SK、STS、Bucket URL、对象存储域名、云元数据或 K8s ServiceAccount。
- 准备确认云凭据权限、对象存储读写、Bucket 接管或云账号能力。
- 准备写报告前做误判过滤和最小证据闭环。

---

## 横向判断表

| 入口信号 | 失败现象 | 转向动作 | 关键证据 | 评级边界 | 误判过滤 |
|---|---|---|---|---|---|
| AK/SK、STS、Bucket URL、对象存储子域 | 只有疑似字符串或 URL | 先做归属和存在性判断,再做最小权限验证 | 来源位置、脱敏字段类型、归属证据 | 线索最低,不单独高危 | 疑似 AK/SK 不等于有效凭据 |
| 云凭据调用 API | 全部 AccessDenied | 只保留身份或无效凭据证据;转敏感信息低危 | 身份响应、错误码、服务范围 | 无可用权限时不高危 | AccessDenied 不等于可利用 |
| 云账号可只读枚举 | 能列服务或资源名 | 只取最小脱敏样例,停止扩大枚举 | 身份、地域、服务、只读资源类型 | 账号级敏感权限高 | 不批量下载、不横向扩展 |
| Bucket 返回 AccessDenied | 无法列目录 | 不报可读/可写;转找公开对象、策略文件、同主体子域 | AccessDenied 响应和后续可用证据 | 仅说明存在或受保护 | AccessDenied 不能证明可读/可写 |
| 可列/可读对象 | 列表或对象可访问 | 只取最小样例和字段类型 | ListObject、非公开对象类型、脱敏样例 | 可列/可读中起 | 公开静态资源不等于敏感泄露 |
| 可写/可覆盖 | 写入或覆盖可能 | 仅写自有测试 key;覆盖只测自有对象 | 自有对象写入/覆盖、权限边界 | 可写/覆盖/接管高危候选 | 不覆盖真实文件、不上传恶意脚本 |
| `NoSuchBucket` 或类似不存在 | 桶名不存在 | 仅在授权和无破坏条件下评估接管可能 | 归属、可注册性、业务引用关系 | 接管链完整才高 | 不抢注、不接管真实业务资源 |
| 元数据返回 | 无凭据 | 评估网络、角色名、用户数据是否可级联 | 元数据路径、角色/网络信息、SSRF 入口 | 单独不报高危 | 元数据基础信息不等于云接管 |
| K8s ServiceAccount | token 可读但权限未知 | 只做身份和最小只读 API 能力 | namespace、SA、只读 API 响应 | 取决于 RBAC 权限 | 不读取 Secret 或扩大集群枚举 |

## 最小证据包

- 来源: 文件、JS、接口响应、元数据、上传返回包或配置项位置。
- 归属: 云厂商、账号/项目、地域、Bucket/资源名、角色或服务账号。
- 权限: 身份确认、可用服务、读/列/写/覆盖/只读 API 范围。
- 样例: 只取最小脱敏对象、字段类型、错误码和 flow id。
- 边界: 已停止的高风险动作、HITL 授权状态和未做的枚举/写入/删除。

---

## 评级口径

- 疑似字符串、公开 URL、AccessDenied、元数据基础信息: 线索或低危 candidate。
- 有效身份但无权限: 通常低中,取决于凭据敏感度和泄露位置。
- 可列/可读非公开对象、可读取配置或少量敏感样例: 中高危候选。
- 可写/可覆盖、可创建资源、可读密钥管理/Secret、可执行云命令: High/Critical 候选。
- 多项目、多区域、多实例影响或高权云账号: Critical 候选,必须 HITL 最小化验证。

---

## HITL 边界

- 使用云 AK/SK、STS、RAM/CAM、ServiceAccount 或管理 API 前,先确认授权范围。
- 写入、覆盖、创建、删除、下载大文件、读取 Secret、执行命令、横向枚举都必须 HITL。
- 只允许自有测试 key、自有对象、自有路径和最小只读验证。

---

## 报告前误判过滤

- 不把公钥、publishable key、Mapbox/Stripe 前端 key 当云私钥。
- 不把对象存储脚本上传当 RCE; OSS/COS/S3/MinIO 默认不执行脚本。
- 不把公开静态资源、空桶、默认 health 信息当敏感泄露。
- 不输出真实 AK/SK、Token、内部 IP、手机号、身份证、账号密码或大批量对象名。
